Interior Plan

内装・竣工写真

空間の魅力まで伝わる写真を。

企業さま向けの内装写真・竣工写真の撮影プランです。「ただ空間がわかる」写真ではなく、「その空間の魅力が伝わる」写真を心がけています。前職の設計・デザインの経験を活かして撮影します。

撮影までの流れ

  1. お見積もり

    公式LINEにて撮影概要をお伺いした後、お見積もりをいたします。

  2. お打ち合わせ

    必要なカットなどについてお打ち合わせをします。

  3. 撮影

    お写真をご確認いただきながら撮影を進めます。

  4. 納品・ご請求

    2週間以内に納品と請求書の発行をいたします。指定の口座へお振り込みをお願いします。

ご注意事項

  • 交通費は大宮駅からの往復分をいただいています。撮影状況により変更になる場合がございます。
  • 平米数や撮影内容によって追加料金をいただく場合がございます。お見積もりは公式LINEにてご連絡ください。
  • 基本的には撮影日より2週間以内に納品いたします。お急ぎの際はご相談ください。

ご予約の前に必ずご予約の流れ・ご利用案内をご確認ください。
その他ご質問や空き日程の確認は、お気軽に公式LINEにてご連絡ください。
