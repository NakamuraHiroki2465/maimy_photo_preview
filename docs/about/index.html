About

わたしについて

mai yamadaまい

フリーランスのカメラマンをしております、「まい」と申します。実家は福島県、現在は埼玉県に住んでいます。

前職は設計・デザイン職で、大学ではデザインについて学んでいました。カメラマンは小さい頃からの夢で、今こうしてたくさんのご家族にお会いでき、素敵なご縁に恵まれて、とても幸せ者だと思っています。

Philosophy

“自然であったかくて、
思わず笑顔になるような”

そんな写真を撮るのが得意です。

私が写真を撮る理由は、どのツールよりも「伝わるもの」があると思っているからです。私が見た幸せや感動、こんなにも幸せが溢れていることを伝えたい。

忙しい日々の中で見逃してしまいがちな、目の前にある幸せが実感できるように。
自分をもっと好きになれるように。
写真を見返したときに幸せな気持ちになるように。
私が撮った写真が、心を温かく包み込みますように。

そんな想いを胸に、日々活動しております。

For You

はじめての撮影でも大丈夫

子どもが泣いてしまったらどうしよう

撮られるのが苦手…上手く笑えるかな

撮影を申し込むにあたって、不安なことがたくさんあると思います。特に初めての撮影となると、どうすればいいか分からないことも多くて緊張しますよね。その不安を一緒に考えながら、解決していけたらと思っています。

ぜひお気軽にご相談ください。皆さまにお会いできるのを楽しみにしています！
